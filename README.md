# Homebrew tap for ai-agentic-tools

```sh
brew install ai-agentic-tools/tap/foil
```

[Foil](https://github.com/ai-agentic-tools/Foil) is a local sandbox for AI
coding agents: instant copy-on-write branches of your repo, reviewed before
they are committed. The formula installs the release binary (macOS universal,
Linux x86_64) and checks its SHA-256.

On Ubuntu 23.10 and later, run `sudo foil setup` once after installing.
